01 · What It Solves

把模型能力变成可操作的政策分析界面

原始模型适合研究人员维护，网页工作台适合团队协作、情景复现和结果交付。CN OMEGA 保留 Python 模型的可追溯输出，同时把高频参数和政策输入放到浏览器里。

01

情景配置

支持分析年份、信用市场效率、价格响应、续航、生产约束和政策 CSV 输入，减少命令行操作负担。

02

隔离运行

每次网页提交都会启动独立 Python 进程，避免 OMEGA 模型全局状态互相污染，便于复现和排查。

03

结果交付

自动汇总关键指标、趋势序列和输出文件列表，让非代码用户也能查看和下载完整结果。

02 · Workflow

从政策假设到模型输出的完整链路

网页服务只负责交互、文件上传、任务管理和结果展示；模型计算仍由本地化 OMEGA 代码完成。这个边界清楚，便于后续迁移到云服务器。

Input

配置政策情景

选择内置输入或上传 CSV，设定年份、市场和技术参数。

Run

启动模型进程

服务端创建运行目录，写入请求参数并调用独立 runner。

Parse

提取摘要指标

读取 summary CSV，生成卡片、趋势序列和文件索引。

Deliver

交付结果包

在网页查看状态、日志、图表，并下载原始输出文件。

04 · Deployment

本地运行和云服务器运行都可以

宣传页可以免费放在 GitHub Pages；真正运行模型的网页工作台需要 Python 后端。如果部署到云服务器，用户访问服务器域名和端口即可使用。

本地模式

用户下载项目，在自己的电脑运行 `python web_app.py`，浏览器访问 `127.0.0.1:8765`。

局域网模式

在一台工作站运行服务并监听 `0.0.0.0`，同一网络内的成员访问该机器 IP 和端口。

云服务器模式

把项目部署到云服务器，配置登录、反向代理和权限控制，用户通过域名进入工作台。

# local preview
python web_app.py

# browser
http://127.0.0.1:8765

# server / LAN
$env:OMEGA_WEB_HOST="0.0.0.0"
$env:OMEGA_WEB_PORT="8765"
python web_app.py
